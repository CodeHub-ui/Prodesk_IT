# Prodesk IT - Responsive Landing Page

A modern, responsive corporate landing page built with HTML, CSS, and JavaScript. The project showcases Prodesk IT's services, company information, and contact section with a clean UI, mobile-friendly navigation, and dark/light theme support.

---

## Live Demo

Deploy the project using  Netlify (https://prodeskit-landing-page.netlify.app/).

---

## Features

- Responsive design for desktop, tablet, and mobile devices
- Sticky navigation bar
- Mobile hamburger menu
- Light/Dark mode toggle
- Modern Hero section
- Services section with feature cards
- About section
- Call-to-Action (CTA) section
- Clean footer
- Semantic HTML5 structure

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
